# 🌐 My Portfolio Website

A modern, fully responsive personal portfolio website built with pure **HTML, CSS, and JavaScript** — no frameworks needed!

## 📋 Features

- 🖼️ **Hero Section** — circular photo frame with glowing border effect
- 👤 **About Me** — clean, professional bio section
- 🛠️ **Skills** — HTML / CSS / JS cards with animated progress bars
- 💼 **Projects** — showcase cards for your work
- 📬 **Contact Form** — working demo form with success feedback
- 📱 **Fully Responsive** — mobile-friendly with a hamburger menu
- ✨ **Scroll Animations** — sections fade in as you scroll
- 🌙 **Modern Dark Theme** — blue/purple gradient accents

## 📂 Project Structure

```javascript
portfolio/
│
├── portfolio.html    ← the whole website (single file)
└── my-photo.jpg      ← your profile photo
```

> **Note:** The entire site (HTML + CSS + JS) lives in one file, so it's easy to host, share, or upload anywhere.

---

## 🚀 How to Use

1. **Download** `portfolio.html`
2. **Add your photo:**

- Save your picture in the same folder as `portfolio.html`
- Rename it to **`my-photo.jpg`**
- It will appear automatically in the circular frame

3. **Open** `portfolio.html` in any browser (double-click it)

---

## ✏️ How to Customize

Open `portfolio.html` in any text editor (VS Code, Notepad, etc.) and edit:

| What to Change | Where to Find It |
| --- | --- |
| Your name | Search for `Your Name` |
| Hero intro text | `<p>` right below your name |
| About Me text | Inside the `#about` section |
| Skill levels | `width:90%`, `width:85%`, `width:75%` in the bars |
| Projects | Inside `#projects` — change titles, descriptions, and emoji |
| Footer | Bottom of the page, search for `Your Name` |
